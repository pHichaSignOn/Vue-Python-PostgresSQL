	>>ติดตั้งไลบรารี
	5.(env)pip install Flask psycopg2-binary python-dotenv bcrypt flask-cors PyJWT flask-jwt-extended    

	6.(env)pip install Flask 	
	7.(env)pip install --upgrade pip
	8.(env)pip install psycopg2 เป็น ไลบรารีที่ใช้เชื่อมต่อ PostgreSQL Database จาก Python 
	pip install psycopg2-binary แนะนำใช้ psycopg2-binary ถ้าเป็น development/test
	9.(env)pip install python-dotenv อ่านค่า environment variables จากไฟล์ .env
	10.(env)pip install bcrypt ใช้ bcrypt → ปลอดภัยกว่า
	11.(env)pip install flask-cors ใช้ CORS หรือ CSRF (เวลารันจากเว็บเบราเซอร์)
	12.(env)pip install PyJWT เพราะ JWT_SECRET_KEY ไม่ใช่ package ที่ต้องติดตั้ง แต่เป็น environment variable (ค่าตั้งค่า) ที่เราต้องกำหนดเองเพื่อเก็บ secret key ที่ใช้เข้ารหัส/ถอดรหัส JWT token
	13.(env)pip install flask-jwt-extended
